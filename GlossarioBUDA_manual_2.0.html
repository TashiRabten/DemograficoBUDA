1. Introdução -> Índice

O GlossarioBUDA é um aplicativo de gestão de terminologia budista que permite:

  • 📚 Gerenciar termos em múltiplos idiomas (Tibetano, Sânscrito, Pali, Inglês, Português, Chinês, etc...)
  • 🔍 Buscar termos com suporte a diacríticos (śamatha = samatha)
  • 📱 Exportar termos formatados para WhatsApp
  • 🪟 Vista compacta sempre visível com ferramenta de diacríticos
  • 📦 Importar glossários no formato XML, CSV e JSON
  • ✓ Sistema de verificação de status (rascunho, revisado, verificado, aprovado)
  • 🔄 Sincronização com a nuvem para backup e compartilhamento

2. Instalação -> Índice

Windows

  1. Baixe o arquivo GlossarioBUDA-x.x.x.exe do site
  2. Execute o instalador
  3. Siga o assistente de instalação
  4. O aplicativo será instalado em C:\Program Files\GlossarioBUDA
  5. Um atalho será criado na área de trabalho

macOS

  1. Baixe o arquivo GlossarioBUDA-x.x.x.pkg do site
  2. Abra o arquivo .pkg
  3. Siga o assistente de instalação
  4. O aplicativo será instalado em /Applications

CASO HAJA PROTEÇÃO do WINDOWS ou MAC

Primeiro Lançamento

Na primeira execução, o aplicativo:

  • Criará automaticamente o banco de dados terms.db
  • Verificará por atualizações disponíveis
  • Estará pronto para uso imediato

4. Busca de Termos -> Índice

Busca Básica

  1. Digite qualquer texto no campo de busca
  2. Os resultados aparecem automaticamente enquanto você digita
  3. A busca funciona para:
    • Termo original
    • Tradução
    • Contexto
    • Contribuidor
    • Notas
    • Aceita termos de uma única letra (ex: "I" em inglês)

Busca com Diacríticos

A busca é insensível a diacríticos. Você pode buscar de três formas:

Digite Encontra
samatha śamatha, samatha, sāmatha
śamatha śamatha, samatha, sāmatha
sāmatha śamatha, samatha, sāmatha

Busca Tibetana no Windows

  1. Clique no botão བོད་ ao lado do campo de busca
  2. Clique "OK" para transferir para o campo de busca
  3. Os resultados aparecem automaticamente

Paginação

  • A busca mostra 100 resultados por página
  • Se houver mais resultados, o botão "Carregar mais" aparece na parte inferior
  • Clique para carregar os próximos 100 resultados
  • Os novos resultados são adicionados à lista existente

Ver Termos Recentes

  1. Clique no botão 🕒 Recentes
  2. Mostra os 50 termos mais recentemente adicionados
  3. Útil para revisar suas últimas entradas

Abrir Editor

Método 1 - Botão:

  1. Com o termo selecionado, clique no botão ✏️ Editar

Método 2 - Menu de Contexto:

  1. Clique com o botão direito no termo na lista
  2. Selecione "Editar Termo" no menu

  1. Clique duas vezes com o botão esquerdo no termo da lista no termo na lista

Na edição, você tem acesso ao campo Status:

9. Entrada de Texto Tibetano -> Índice

⚠️ Importante para usuários Windows: A entrada de caracteres tibetanos com subscripts (usando Alt/Option + tecla) não funciona diretamente nos campos de texto do JavaFX no Windows. Use sempre o botão བོད་ para entrada de texto tibetano.

No macOS

Usuários de macOS podem digitar tibetano diretamente nos campos usando o teclado tibetano do sistema:

  • Configure o teclado tibetano nas Preferências do Sistema
  • Use ; (ponto e vírgula) para criar subscripts
  • Exemplo: ག + ; + ཡ = གྱ

Ou

  • Use controle para criar subscripts
  • Exemplo: ག + controle + ཡ = གྱ

No Windows

Usuários de Windows devem usar o Tibetan Input Helper:

  1. Clique no botão བོད་ azul ao lado de qualquer campo
  2. Digite usando transliteração Wylie
  3. O texto tibetano aparece automaticamente
  4. Clique "OK" para transferir o texto

11. Importação de glossarios -> Índice

Gerar Arquivos Compatíveis (XML / CSV / JSON) com a IA

O GlossarioBUDA utiliza uma base de dados SQLite (terms.db) gerenciada pelo componente DatabaseManager. Você pode importar ou gerar arquivos compatíveis para integração, backup ou migração usando os formatos CSV, JSON ou XML.

🧩 Estrutura esperada

CampoDescrição
source_termTermo original
source_languageIdioma de origem (ex: sa, bo, en, pt)
target_termTradução ou termo-alvo
target_languageIdioma da tradução
contextContexto opcional ou nota de uso
contributorNome de quem adicionou o termo
notesObservações adicionais

📄 Exemplo de CSV

source_term,source_language,target_term,target_language,context,contributor,notes
karma,sa,action,en,"philosophical term","Tashi","root concept"
śūnyatā,sa,emptiness,en,"Buddhist philosophy","Tashi","key Mahayana term"

🧾 Exemplo de JSON

[
  {
    "source_term": "karma",
    "source_language": "sa",
    "target_term": "action",
    "target_language": "en",
    "context": "philosophical term",
    "contributor": "Tashi",
    "notes": "root concept"
  },
  {
    "source_term": "śūnyatā",
    "source_language": "sa",
    "target_term": "emptiness",
    "target_language": "en",
    "context": "Buddhist philosophy",
    "contributor": "Tashi",
    "notes": "key Mahayana term"
  }
]

🧠 Exemplo de XML

<terms>
  <term>
    <source_term>karma</source_term>
    <source_language>sa</source_language>
    <target_term>action</target_term>
    <target_language>en</target_language>
    <context>philosophical term</context>
    <contributor>Tashi</contributor>
    <notes>root concept</notes>
  </term>
  <term>
    <source_term>śūnyatā</source_term>
    <source_language>sa</source_language>
    <target_term>emptiness</target_term>
    <target_language>en</target_language>
    <context>Buddhist philosophy</context>
    <contributor>Tashi</contributor>
    <notes>key Mahayana term</notes>
  </term>
</terms>

💡 Como pedir para a IA gerar arquivos compatíveis

Você pode solicitar à IA:

Gere um arquivo CSV (ou JSON/XML) compatível com o formato DatabaseManager do GlossarioBUDA, com os campos source_term, source_language, target_term, target_language, context, contributor e notes.

A IA fornecerá um conteúdo pronto para ser salvo em um arquivo .csv, .json ou .xml, que poderá ser importado diretamente para o banco de dados do aplicativo.

🪶 Importando os arquivos

Aperte no botão de carregar dados, selecione o arquivo gerado (CSV, JSON ou XML).

Esses formatos são totalmente compatíveis com o sistema do GlossárioBUDA, garantindo que os dados possam ser carregados, sincronizados e atualizados corretamente sem editar o banco de dados diretamente.

13. Status de Verificação -> Índice

Cada termo possui um status que indica seu nível de revisão e aprovação.

Níveis de Status

Status Descrição Uso Recomendado
draft Rascunho Termo recém-adicionado, ainda não revisado
reviewed Revisado Termo passou por primeira revisão
verified Verificado Termo verificado por especialista ou fonte confiável
approved Aprovado Termo oficialmente aprovado para uso público

Alterar Status

  1. Selecione o termo na lista
  2. Clique em ✏️ Editar
  3. No campo "Status", selecione o novo status
  4. Clique em "Salvar"

Fluxo de Trabalho Sugerido

  1. Adição: Novo termo começa como "draft"
  2. Revisão: Após verificação básica, mude para "reviewed"
  3. Verificação: Após consulta com especialista ou fonte, mude para "verified"
  4. Aprovação: Quando estiver pronto para uso público, mude para "approved"

15. Sincronização com a Nuvem -> Índice

O Glossário BUDA permite sincronizar seus termos com a nuvem para backup e compartilhamento entre dispositivos.

Sincronizar Dados

  1. Clique no botão 🔄 Sincronizar
  2. Uma janela de sincronização aparece com opções

Opções de Sincronização

Enviar Dados Locais para a Nuvem

  • Marque o checkbox "Enviar dados locais para a nuvem"
  • Clique em "Sincronizar"
  • Seus termos locais serão enviados para o servidor
  • Útil quando você adiciona novos termos e quer compartilhá-los

Baixar Dados da Nuvem

  • Deixe o checkbox desmarcado (padrão)
  • Clique em "Sincronizar"
  • Os termos da nuvem serão baixados para seu dispositivo
  • Útil para atualizar seu banco de dados local

Verificar Duplicatas

O sistema possui verificação automática de duplicatas:

  1. Durante a sincronização, o aplicativo verifica se há termos duplicados
  2. Se encontrar duplicatas locais, você será notificado
  3. Você pode escolher manter ou remover as duplicatas
⚠️ Importante: Sempre faça backup do seu banco de dados terms.db antes de sincronizar pela primeira vez. A sincronização pode sobrescrever dados locais se houver conflitos.

Boas Práticas de Sincronização

  • Sincronize regularmente para manter seus dados atualizados
  • Envie para a nuvem após adicionar vários termos novos
  • Baixe da nuvem ao começar a trabalhar em um novo dispositivo
  • Verifique duplicatas periodicamente para manter o banco de dados limpo

Status da Sincronização

Durante o processo de sincronização, você verá mensagens de status:

  • "Conectando ao servidor..."
  • "Enviando dados..."
  • "Baixando dados..."
  • "Verificando duplicatas..."
  • "Sincronização concluída com sucesso!"

16. Autorização do Aplicativo (Windows/ MacOS) -> Índice

Se o sistema operacional (Windows, macOS ou antivírus) bloquear o GlossarioBUDA por ser um aplicativo não assinado, siga os passos abaixo para autorizar de forma segura. Isso não é contornar a proteção, mas sim informar ao sistema que o aplicativo é confiável.

🪟 Windows (Defender SmartScreen ou Antivírus)

  1. Execute o instalador ou o executável normalmente. Se aparecer a janela azul do Windows Defender dizendo "O Windows protegeu o seu computador", clique em:
    Mais informações → Executar assim mesmo.
  2. Para antivírus (AVG, Avast, etc.): Se o aplicativo for colocado em quarentena, abra o antivírus e procure a opção Histórico de Detecções ou Ameaças Recentes. Localize o GlossarioBUDA e selecione Restaurar e adicionar à lista de exceções.
  3. Para execuções futuras: O aplicativo será lembrado como confiável e não voltará a ser bloqueado, a menos que seja reinstalado em outro local.

🍎 macOS (Gatekeeper)

  1. Ao tentar abrir o aplicativo, pode aparecer a mensagem "Não é possível abrir porque não foi possível verificar o desenvolvedor". Vá em Preferências do Sistema → Segurança e Privacidade → Geral e clique em Abrir assim mesmo.
  2. Alternativamente, segure Ctrl e clique sobre o aplicativo, depois selecione Abrir. O macOS perguntará se deseja abrir mesmo assim — confirme.

Esses passos garantem que o aplicativo seja executado de forma legítima e segura, mantendo as proteções do sistema ativas.

18. Solução de Problemas -> Índice

Problema: Entrada tibetana no Windows não funciona

Solução:

  • Use sempre o botão བོད་ para entrada tibetana no Windows
  • A entrada direta de subscripts tibetanos não funciona no JavaFX no Windows
  • No macOS, a entrada direta funciona normalmente

Problema: Banco de dados não carrega termos

Solução:

  • Verifique se o arquivo terms.db existe em:
    • Windows: C:\Users\[SeuNome]\documentos\.glossariobuda\terms.db
      • OBS! Se não encontrar a pasta neste local, certifique-se que está na pasta do windows não da nuvem
        • A pasta do windows é bege não é de emoji
    • macOS: /Users/[SeuNome]/documentos/.glossariobuda/terms.db
  • Se o arquivo estiver corrompido, restaure de um backup
  • Se não houver backup, importe novamente o glossário XML

Problema: Busca não encontra termos com diacríticos

Solução:

  • A busca deve funcionar independente de diacríticos
  • Tente buscar sem diacríticos primeiro (ex: samatha em vez de śamatha)

Problema: Exportação para WhatsApp perde formatação

Solução:

  • Use Ctrl+A e Ctrl+C para copiar todo o texto
  • Cole diretamente no WhatsApp sem editar
  • Emojis e quebras de linha devem ser preservados

Problema: Importação de glossário falha

Solução:

  • Verifique se o arquivo XML está no formato correto
  • Certifique-se de o csv não está em uma só linha
  • Certifique-se que o excel está configurado para receber UTF-8 (com suporte de diacríticos)
  • Verifique os logs de erro para detalhes específicos
  • Tente importar um arquivo menor primeiro para testar

Problema: Sincronização falha

Solução:

  • Verifique sua conexão com a internet
  • Certifique-se de que o servidor está acessível
  • Tente novamente após alguns minutos
  • Se o problema persistir, faça backup local do seu banco de dados

Problema: Duplicatas após sincronização

Solução:

  • Use a função de verificação de duplicatas
  • Revise manualmente os termos duplicados
  • Remova as duplicatas desnecessárias
  • Sincronize novamente para atualizar a nuvem

Problema: Caracteres tibetanos não aparecem corretamente

Solução:

  • Instale fontes tibetanas no seu sistema:
    • Windows: Instale fontes como "Jomolhari", "Himalayan" ou "Tibetan Machine Uni"
    • macOS: Fontes tibetanas geralmente já estão incluídas
  • Reinicie o aplicativo após instalar fontes
