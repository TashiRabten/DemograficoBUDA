Manual do Usuário — DemograficoBUDA

Bem-vindo ao DemograficoBUDA. Este guia ajuda qualquer pessoa a registrar entrevistas, consultar os dados e sincronizar as informações com a nuvem. Nada aqui exige conhecimentos técnicos: basta seguir as telas e observar as dicas abaixo.

1. Acesso e login -> Índice

Ao abrir o DemograficoBUDA aparece uma tela simples de login. Informe apenas seu nome de usuário (algo como maria\_coletora). Não há senha e os dados ficam registrados localmente, permitindo saber quem coletou cada entrevista.

  • Registrar usuário: cria ou atualiza seu nome.
  • Entrar: carrega o painel principal.
  • Sair: limpa o usuário atual (útil para troca de operador).

2. Registrar entrevistas -> Índice

A tela principal está dividida em três blocos: status, dados do entrevistado e hábitos de leitura. Os campos se comportam da seguinte forma:

  • Nome: único campo obrigatório na seção demográfica. Idade, sexo, tradição, templo e tempo de prática podem ficar em branco.
  • Tipo de leitura: obrigatório. Os demais campos da leitura são opcionais.
  • Data da entrevista: pode ser preenchida no cabeçalho; se vazia, fica registrada como “sem data”.

Após preencher o que for necessário clique em Salvar leitura. A mensagem no rodapé confirma se o registro ficou apenas local ou se também foi enviado à nuvem.

Dica: Use os botões “Limpar Leitura” para manter os dados da pessoa e registrar várias obras em sequência, ou “Limpar Tudo” para começar uma nova entrevista.

3. Visualizar e editar pessoas -> Índice

O botão Visualizar Dados abre a lista de entrevistados. Cada linha representa uma pessoa e mostra um resumo das obras cadastradas.

Principais ações

  • Filtros por data: selecione uma data inicial/final para reduzir a lista.
  • Visualizar / Editar: abre um painel com as informações da pessoa e um menu suspenso para escolher qual obra editar.
  • Excluir Pessoa: remove tudo daquela pessoa, local e na nuvem.
  • Exportar CSV: gera uma planilha com todas as leituras visíveis.
No painel de edição: escolha a obra no dropdown, altere os campos desejados e clique “Salvar alterações”. É possível excluir apenas a obra selecionada usando o botão “Excluir leitura”.

4. Exportar e compartilhar -> Índice

Use o botão Exportar CSV na tela de visualização para gerar um arquivo compatível com Excel, Google Sheets ou outras ferramentas. Campos em branco aparecem como células vazias.

  • Escolha a pasta e o nome do arquivo ao exportar.
  • Se não houver registros filtrados, o sistema avisa que não há nada para salvar.

5. Sincronizar com a nuvem -> Índice

Clique em Sincronizar na tela principal para enviar entrevistas ainda não sincronizadas para o Supabase. Algumas dicas:

  • Certifique-se de que a conexão está ativa (botão “Testar Conexão”).
  • Se o Supabase tiver restrições de unicidade antigas, o sistema tenta reaproveitar registros, mas o ideal é remover o índice exclusivo em leituras e permitir campos nulos em entrevistados.
  • Após concluir, os contadores de “Locais”, “Não Sincronizadas” e “Nuvem” são atualizados.

6. Dicas rápidas e atalhos -> Índice

  • Botões responsivos: os botões crescem conforme o texto, evitando cortes.
  • Seleção discreta: ao escolher uma linha na tabela, apenas um contorno cinza aparece (sem preencher com azul).
  • AutoUpdater: ao abrir, o sistema verifica se há nova versão. Caso não exista release pública, ignora o aviso.
  • Scripts de instalação: use build-windows-jpackage.bat e build-macos-jpackage.sh para gerar instaladores que podem ser distribuídos para outras máquinas.

7. Perguntas frequentes -> Índice

Posso deixar campos em branco?

Sim. Apenas “Nome” (no cadastro da pessoa) e “Tipo de leitura” são obrigatórios.

Voltar ao índice

Como descubro se algo ficou na nuvem?

O rodapé mostra quantas leituras estão pendentes. Ao sincronizar, uma mensagem indica quantas entrevistas foram enviadas.

Voltar ao índice

O que fazer se o Supabase recusar registros duplicados?

Remova o índice exclusivo ux_leituras_por_obra ou mantenha-o apenas se as leituras realmente não puderem se repetir. O sistema tenta atualizar registros existentes, mas o cenário ideal é permitir múltiplas obras semelhantes por pessoa.

Voltar ao índice

Onde ficam os arquivos locais?

No Windows, procure em C:\Users\SEU_USUARIO\Documents\DemograficoBUDA\. Lá estão os bancos SQLite (leituras_buda.db e demografico_users.db).
