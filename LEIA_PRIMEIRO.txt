🎯 INÍCIO RÁPIDO - 3 PASSOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1: CONFIGURAR O SUPABASE
────────────────────────────────────────────────────────────────────
   1. Abra: SUPABASE_SETUP.md
   2. Siga as instruções para criar a tabela no Supabase
   3. Copie e execute o script SQL fornecido


PASSO 2: EXECUTAR O PROGRAMA
────────────────────────────────────────────────────────────────────
   WINDOWS:
   → Duplo-clique em: run.bat

   LINUX/MAC:
   → Terminal: mvn javafx:run


PASSO 3: COMEÇAR A COLETAR DADOS
────────────────────────────────────────────────────────────────────
   1. Clique em "Testar Conexão"
   2. Preencha o formulário
   3. Clique em "Salvar Entrevista"
   4. Pronto! 🎉

💡 FUNCIONALIDADES PRINCIPAIS

✅ Coleta de dados demográficos
   → Nome, idade, sexo, tradição budista
   → Templo, tempo de prática
   → Mesclou tradições (Sim/Não)
   → Observações

✅ Armazenamento Dual
   → Local: SQLite (funciona offline)
   → Nuvem: Supabase (centralizado)

✅ Sincronização Inteligente
   → Automática quando online
   → Manual via botão
   → Status visual

✅ Estatísticas em Tempo Real
   → Total local
   → Não sincronizadas
   → Total na nuvem
